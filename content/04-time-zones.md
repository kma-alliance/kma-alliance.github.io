KMA has members on every continent, so every time in alliance mail should say which clock it uses. This page converts between them.

Two clocks matter:

- **UTC** drives the Alliance Duel. Each Duel day resets at **00:00 UTC**.
- **Server time** is the clock shown in-game. The wiki reports it as UTC-2 for global servers. Elixir Scramble windows (09:00, 18:00, 23:00) and the Cheese Trap difficulty lock (22:00) are in server time. If the server clock below does not match your in-game clock, change the offset and it is remembered on your device.

> **KMA:** When you post an event time, write it as server time **and** UTC, for example "Hunt Battle 20:00 server / 22:00 UTC". Members can then read this page for their own zone. Officer-started events (Hunt Battle, Expedition, Cheese Trap, Undead Siege, Pandemic bosses) are scheduled for the hour with the most members online, which leadership works out from the "Right now there" column.
