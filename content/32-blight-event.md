> **Unverified name:** guide sites call this **Hunt Battle**, but that name never appears in a player video or on any official page, so this page uses a plain description instead. A player walkthrough calls a Blight event "Eliminate Blight", which may be the real label. It is not [Thief Hunt](#/thief-hunt), which is a separate, well-documented event, and not [Wandering Phantom](#/wandering-phantom), whose Blights roam the whole kingdom. Tell an officer what your event screen calls it.

## At a glance

| | |
|---|---|
| Started by | R4 or R5 |
| Needs | 20+ members online |
| Attempts | One per event period. Difficulty is locked once chosen. |
| Prep | 5 minutes after launch before Blights spawn |
| March | Fixed 15 seconds each way, no matter where you live |
| Pays | 500 Alliance Coins per Blight, 2,500 per boss, Gearstone and resources by difficulty |

## How it works

After launch, spawn points appear across alliance territory. Everyone marches on the Blights; each one that dies pays the whole alliance. The wiki describes 5 waves of 30 Blights plus a boss across 9 difficulties. Some guides describe 15 waves. Check the wave counter in-game and tell an officer which it is.

Rewards scale with **total Blights killed**, not waves reached. A full clear one difficulty lower beats an unfinished run higher.

## KMA plan

> **KMA:** This event fires once, so it runs at the peak-online hour announced a day ahead in alliance mail. Show up five minutes early.

1. One shot-caller in chat names the Blight. **Everyone hits that one** until it dies, then the next.
2. No idle time. The moment a march returns, send it again.
3. Officers fire alliance buffs before the last waves, not after a wave goes wrong.
4. First cycle, pick one difficulty below your guess. Move up once you full-clear.

## Mistakes

- Spreading marches across several Blights so none dies before the wave timer.
- Choosing a difficulty for the strongest member instead of the median.
- Starting it when fewer than 20 people are online.
