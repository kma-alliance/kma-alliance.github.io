Codes are case-sensitive, one redemption per account, and can expire without notice. Tap **copy** next to a code, then paste it in-game. Rewards arrive in Mail.

## Live scanner

A script on GitHub checks eight public code trackers every 6 hours and updates this list automatically. **Working** means every tracker that lists it says it works. **Disputed** means at least one tracker says it has expired. Try disputed codes anyway; they cost nothing.

## How to redeem

**Android, in-game:**

1. Tap your avatar (top-left).
2. Tap Settings (the gear).
3. Tap Gift Code.
4. Paste the code exactly, no trailing space, and confirm.
5. Collect from Mail.

**iOS:** several trackers say the in-game button is Android-only; others say it works on both. If you do not see it, use the web portal at [gevents.globallap.com](https://gevents.globallap.com/gamecode/index.html?gameId=440): log in with the linked Facebook or Google account or an email code, pick your server and character, enter the code.

You must finish the tutorial first. Some codes are region or server limited.

## Where new codes come from

The pattern so far is "LA" + occasion + "26" for holidays (LAVD26, LAEGG26, LADOG26) and "LA" + a number series for campaign codes (LA30W7F2M, LA25W8CM, LA20WBZ9, LA15WPN4D), with a new one roughly every 2 to 3 weeks. They drop first on the official [Discord](https://discord.com/invite/rxVwBW5d9f) and [Facebook](https://www.facebook.com/lastasylumglobal/). If you see a new one, post it in alliance chat and tell an officer so this page gets updated.
