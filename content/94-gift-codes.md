Gift codes are free diamonds, speedups and resources. They cost nothing to try, but they are **case-sensitive**, usually work **once per account**, and most **expire within days**. Tap **copy** next to a code, paste it in, and collect the rewards from your **Mail**.

## Live scanner

A script checks eight public code trackers every 6 hours and updates this list by itself.

- **Working**: at least one tracker lists it as working and none lists it as expired.
- **Disputed**: trackers disagree. Try it anyway; a failed code costs nothing.
- **Unconfirmed**: no tracker has listed it recently. After three weeks without a sighting it is marked expired.

<div data-widget="codes"></div>

Trackers copy each other and are slow to remove dead codes, so "Working" means "reported working", not "tested today". The only real test is redeeming it.

## Why codes expire

Most codes are tied to an **event or a holiday** and live for **days rather than months**. There is no countdown in the game: a code simply stops working one day, and a tracker may keep listing it for weeks afterwards.

The pattern so far:

| Kind | Example | Typical life |
|---|---|---|
| Holiday codes | `LAVD26` (Valentine's), `LAEGG26` (Easter), `LADOG26` | Around the holiday, sometimes longer |
| Campaign series | `LA15WPN4D`, `LA20WBZ9`, `LA25W8CM`, `LA30W7F2M` | Released one after another |
| Partner and launch codes | `LAPGPOFF` (PocketGamer), `LAiOSLA` (iOS launch) | Unknown. Some are still listed months later |
| Regional codes | `twlap888`, `LAKR15K9A` | May never work on global servers |

New codes have been appearing every **2 to 3 weeks**. They drop first on the official [Facebook page](https://www.facebook.com/lastasylumglobal/) and [Discord](https://discord.com/invite/rxVwBW5d9f), then spread to trackers. **Redeem the day you see one.**

> **Unverified:** whether a code works once per **account** or once per **character**. The web portal asks you to pick a character, which suggests a second character on another server might be able to use the same code. If you have a second character, try it and tell an officer what happened.

## When a code fails

| What happens | Most likely reason | What to do |
|---|---|---|
| Rejected straight away | A typo, the wrong case, or a space pasted with it | Copy it again from this page. Check O against 0 and l against I |
| Rejected, and you have redeemed it before | One use per account | Nothing to do |
| Rejected everywhere | It has expired | Try the next code. Tell an officer so this page gets updated |
| Rejected for you only | A region or server limit | Skip it and try the next code |
| No Gift Code row in Settings | You are on the App Store version | Use the web portal |
| Accepted, but no rewards | Rewards wait in Mail | Open Mail and collect |
| Web portal finds no character | Logged in with an account the game is not linked to | Use the account linked in the game, or the one-time code login |

## Quick answers

**Where do I redeem on iPhone?** On the web portal at gevents.globallap.com. The in-game button is missing on App Store builds.

**I redeemed a code but got nothing.** Open your Mail. Rewards wait there until you collect them.

**Why does a "Working" code fail?** Trackers are slow to remove expired codes, or the code is limited to a region. Try the next one.

**Where do new codes appear first?** On the official Facebook page and Discord. If you see a new one, post it in alliance chat and tell an officer.
