## Weekly skeleton

| Day | Fixed | Officer-scheduled |
|---|---|---|
| Sunday | Quiz, Duel reset day, Kingdom War points week starts | Hunt Battle or Expedition if timed for the weekend |
| Monday | Duel day 1 Raven, Alliance Shop refresh | |
| Tuesday | Duel day 2 Construction, Expedition arena refresh | |
| Wednesday | Duel day 3 Tech, Demon King | |
| Thursday | Duel day 4 Heroes, Expedition arena refresh | |
| Friday | Duel day 5 Preparation | Hunt Battle, Expedition, Cheese Trap for weekend peak |
| Saturday | Duel day 6 Raid, Demon King, Kingdom War war day, Royal City Scramble, Weekend Boss | Undead Siege after the fighting |

Officer-started events (Hunt Battle, Expedition, Cheese Trap, Undead Siege, Pandemic bosses, Thief Leader rallies) go out in alliance mail with a server time and a UTC time. See [Time zones](#/time-zones).
